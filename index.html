01 · describe('about')

        
Quality is a habit, not a phase.

      

      

        

          
I started in QA by writing test cases and bug reports, and I've moved steadily toward building the automation that runs them. Today I lead functional, regression and API testing at Pathao, and I'm building the team's iOS automation framework with WebdriverIO and Appium using the Page Object Model.

          
Before that I tested health, agriculture and education platforms at mPower, covering household-level health data, immunisation tracking, farmer dashboards and gamified learning apps. These are products where a missed bug lands on real people.

          
I like readable test code, fast feedback loops, and finding the bug before the stand-up does. Lately I've been using Cursor and MCP to speed up automation work.
